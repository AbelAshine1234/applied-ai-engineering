The 9-Step Learning Contract — Demonstrable Engineering Competence
1. Concepts: Understand the underlying theory and mechanics.
2. Guided Code: Build working example from first principles.
3. Independent Tasks: Solve problems without copying tutorials.
4. Module Project: Build the designated production deliverable.
5. Test Suite: Write unit/integration tests covering edge cases.
6. Architecture: Document system latency, footprint and trade-offs.
7. Public Log: Commit to GitHub and publish technical notes.
8. Claude Audit: Run code review prompt against production rubrics.
9. Assessment: Pass hands-on verification before advancing.
